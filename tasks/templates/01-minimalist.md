# Template 01 — Minimalist (`templates/01-minimalist/`)

## SEO angle
Targets: "minimalist html resume template", "simple html resume template".

## Who it's for
Anyone who wants a no-frills, content-first resume with nothing to distract from the text.

## Layout & sections
Single column, generous whitespace. Name + title header, then Summary, Experience,
Education, Skills stacked in order. No photo by default.

## Style direction
- Colors: black/white + one small accent color.
- Fonts: system sans-serif stack, no external font required.
- No borders/boxes — section separation via whitespace and a subtle horizontal rule.

## Customization points
- Accent color and base line-height are the two CSS variables most users will touch.

## Acceptance criteria
- Follows all rules in `../02-design-system.md`.
- Passes `../09-qa-accessibility-checklist.md`.
- Looks complete and balanced with zero images (no photo is the default state, not a
  missing-asset error).
