# Template 05 — Developer / Tech (`templates/05-developer-tech/`)

## SEO angle
Targets: "developer resume template html", "software engineer resume template".

## Who it's for
Engineers/developers who want a resume that nods to their craft without gimmicks.

## Layout & sections
Terminal/code-editor-inspired header (e.g. a `$ whoami` line), skills shown as tag
"badges", an optional GitHub/portfolio links row using plain text labels (no icon fonts).

## Style direction
- Monospace accents on headings/labels only; body text stays a readable sans-serif.
- Subtle syntax-highlight-style accent colors.

## Customization points
- Skill-tag list is a simple `<ul>` — easy to add/remove entries.

## Acceptance criteria
- Follows all rules in `../02-design-system.md`.
- Passes `../09-qa-accessibility-checklist.md`.
- Purely visual theming only — no actual embedded code execution, still zero-dependency.
