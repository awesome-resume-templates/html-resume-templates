# Template 13 — Executive (`templates/13-executive/`)

## SEO angle
Targets: "executive resume template html", "senior leadership resume template".

## Who it's for
C-level/senior leadership candidates.

## Layout & sections
Single column, a prominent "Executive Summary" block up top, "Core Competencies" as a
clean multi-column keyword list, Experience written with achievement-focused bullets.

## Style direction
- Understated luxury: black/charcoal + one metallic-feeling accent (deep gold/bronze
  via CSS color only, no images), refined typography, more whitespace than any other
  template in the set.

## Customization points
- Standard shared variables only — restraint is the point of this template.

## Acceptance criteria
- Follows all rules in `../02-design-system.md`.
- Passes `../09-qa-accessibility-checklist.md`.
- Extra scrutiny on typographic polish/spacing consistency — this template's entire
  value proposition is looking expensive.
