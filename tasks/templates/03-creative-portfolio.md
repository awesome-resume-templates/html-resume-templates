# Template 03 — Creative Portfolio (`templates/03-creative-portfolio/`)

## SEO angle
Targets: "creative resume template html", "designer resume template html".

## Who it's for
Designers/artists who want personality and a place to link selected work.

## Layout & sections
Big bold name/title hero, asymmetric section grid, a "Selected Work" section with
links/thumbnails to portfolio pieces, plus standard Experience/Education/Skills.

## Style direction
- Large expressive heading font (a display Google Font with a solid system fallback).
- Generous, confident use of the accent color.

## Customization points
- Number of portfolio items is trivial to add/remove — one clearly commented `<li>`
  per item.

## Acceptance criteria
- Follows all rules in `../02-design-system.md`.
- Passes `../09-qa-accessibility-checklist.md`.
- Despite bold screen styling, `@media print` flattens color blocks to a print-safe
  layout (no wasted ink, no clipped content).
