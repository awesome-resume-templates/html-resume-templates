# Task 04 — SEO-Optimized Root README

## Goal
Write the root `README.md` so it explains the repo to a human *and* ranks for
"html resume templates" / "free html resume templates" and their long-tail variants.

## Target keywords
- Primary: `html resume templates`, `free html resume templates`.
- Secondary/long-tail (spread naturally across headings/FAQ, never stuffed):
  `ATS friendly resume template html`, `printable resume template`,
  `one page resume template html`, `developer resume template`,
  `dark mode resume template`, `resume template no sign up`,
  `open source resume template`.

## Structure
1. **H1** with the primary keyword, e.g.
   `# Awesome HTML Resume Templates — 20 Free, Open-Source Templates`.
2. **Badges row** — license, GitHub stars, PRs welcome, live demo link.
3. **Intro paragraph (150–200 words)**, natural language, primary + a couple secondary
   keywords, states: free, no sign-up, no build tools, MIT licensed, easy to
   customize, ATS-friendly option included.
4. **Gallery table** — one row per template: thumbnail image, name, 2–3 tag keywords,
   "Live demo" link (→ `docs/` gallery page), "Get this template" link (→ folder).
5. **"Why these templates" section** — free, open source, no tracking, print-ready,
   customizable via CSS variables, works offline.
6. **"How to use" section** — condensed 3-step version of
   [03-template-customization-guide.md](03-template-customization-guide.md), linking
   to the full guide.
7. **FAQ section** (targets featured snippets): "Are these resume templates free?",
   "Are they ATS-friendly?", "How do I convert an HTML resume to PDF?", "Can I use
   these for commercial/job-hunting use?", "How do I contribute a new template?".
8. **Contributing** — short paragraph + link to `CONTRIBUTING.md`.
9. **License** — MIT, short paragraph + link.

## Acceptance criteria
- All 20 templates linked from the gallery table.
- Headings use keyword variants that still read naturally aloud (no stuffing).
- README renders correctly on GitHub (tables, badges, relative image links all resolve).
